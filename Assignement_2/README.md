## Procedura per l'avvio locale del prototipo
Accedere alla cartella appena estratta. Al suo interno è visibile l'intera struttura del sito, comprensiva delle risorse organizzate nelle rispettive directory (se presenti) e dei file sorgente (HTML, CSS, JS).

### Avvio del prototipo
Eseguire un doppio clic sul file principale `index.html`. Il sistema operativo aprirà automaticamente il file all'interno del browser web predefinito (es. Chrome, Safari, Firefox), rendendo la piattaforma immediatamente esplorabile e interattiva.
